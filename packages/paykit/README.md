# @orvacon/paykit

Provider-agnostic, TypeScript-first payment orchestration — the core. Part of **[orvacon](https://github.com/orvacon/orvacon)**: gateways plug in as connectors behind one type-safe API, and your application never knows which gateway runs a payment.

```bash
bun add @orvacon/paykit
```

See the [orvacon guide](https://github.com/orvacon/orvacon#readme) for the full install + usage walkthrough.
