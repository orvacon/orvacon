# orvacon brand

Logo set, rendered by [`../../scripts/gen-logo.mjs`](../../scripts/gen-logo.mjs)
(`bun scripts/gen-logo.mjs` from `apps/web`). All 1024×1024 PNG, accent
`#15B886`. `*-light.png` variants are for light backgrounds.

| File | Use |
| --- | --- |
| `orvacon-mark.png` | **Icon / avatar** — the ring is the "o". GitHub org avatar, app icons, favicon. Reads at any size. |
| `orvacon-lockup.png` | **Primary logo** — mark over the wordmark. READMEs, headers, slides. |
| `orvacon-wordmark.png` | Wordmark only, for wide or inline contexts. |
| `orvacon-wordmark-accent.png` | Wordmark in accent green. |

> The wordmark/lockup use the renderer's default sans, not Geist (which the
> site uses). Close, but swap in Geist before any official wordmark use.
